# Python Fundamentals & CLI Practice

A collection of small Python exercises covering control flow, dictionaries, user input, validation, and simple calculations. This repository documents programming practice alongside my [data analytics portfolio](https://github.com/magedbinlaswad).

## Selected exercises

| Script | Focus |
| --- | --- |

| [student_grade_tracker.py](student_grade_tracker.py) | Score entry, averages, and attendance-based logic |
| [assiment.py](assiment.py) | Loan installment calculations and arithmetic |
| [control_statment.py](control_statment.py) | Control-flow practice |
| [student_discount.py](student_discount.py) | Conditional discount calculations |
| [OTP_verfication.py](OTP_verfication.py) | Verification-flow exercise |

Additional files contain introductory demonstrations and assignments. Original exercise filenames are retained so existing references continue to work.

## Run an exercise

1. Install Python 3.
2. Download or clone this repository and open a terminal in its folder.
3. Run one script at a time, for example:

~~~bash
python app.py
python student_grade_tracker.py
~~~

On systems where Python 3 is named python3, use that command instead. Follow the prompts in the terminal. The selected student-management and grade-tracking examples use Python's built-in functionality; they do not require the data-science packages previously listed in this README.

## Scope

These are independent learning exercises, not a packaged application or production authentication system. Input handling and persistence vary between scripts. In-memory records are lost when the process exits; use fictional data when trying the examples.

The repository does not currently provide a Pandas ETL pipeline, a PySpark workload, or a published visualization. For applied SQL and reporting work, see:
